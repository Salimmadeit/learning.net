The outer directory for this ContosoPizza project. 
Learning ASP .NET Core Web API and HTTP CRUD method implementation from Microsoft Learn.
Cd into the ContosoPizza directory, as the project root, then run the commands "dotnet restore", "dotnet build" and/or "dotnet run" to run this project.
Use the REST Client VS Code extension, Thunder client or Postman to test the GET, POST, PUT and DELETE methods defined in the .http file.

I might use this repository as a main directory to house other .NET learning projects in the future.
